# Lingua

Une application web pour pratiquer l’anglais et progresser vers le niveau B2. Elle propose des leçons de grammaire avec quiz, des sujets d’écriture, des conversations guidées, des vidéos avec questions bilingues et un mini-jeu de vocabulaire.

## Lancer l’application

Ouvre `index.html` dans un navigateur. Aucun outil de compilation ni dépendance n’est nécessaire.

La progression et les brouillons sont enregistrés localement dans le navigateur. Les conversations sont guidées par des répliques prédéfinies ; elles ne sont pas générées par une IA. Les vidéos YouTube ne se chargent que lorsque l’apprenant colle un lien, et les réponses écrites restent enregistrées localement.
